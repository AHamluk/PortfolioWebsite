# Portfolio Website
My first iteration of my portfolio website. Subject to change as I develop my skills.
This project is the source code for a website that displays *my* projects and applicable skills. Each project should have:
* A small graphic
* A description of what the project contains
* Blocks at the bottom that display which skills were used to complete said project.

The site will also contain a page of where to contact me.
All pages will be following a Blue grey color scheme.
